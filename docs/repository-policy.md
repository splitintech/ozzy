# Repository policy

The supported ways to take this source are:

- `git clone https://github.com/splitintech/ozzy.git`
- A GitHub **fork** of `splitintech/ozzy`

Do not delete this upstream repository, its tags, or its published branches. Do not force-push over published history.

GitHub rulesets on this repository block branch and tag deletion and non-fast-forward pushes. Those controls apply to this GitHub project. They cannot stop someone from deleting a copy on their own machine.

The software remains MIT-licensed. GitHub cannot disable copy-paste of a public tree. Use a fork or clone so attribution and history stay attached.
